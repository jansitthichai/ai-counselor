# MindCare

**MindCare : AI เพื่อส่งเสริมสุขภาวะทางอารมณ์และการดูแลสุขภาพจิตสำหรับนักเรียน**

Version **2.0.0** · โรงเรียนสตรีศึกษา

> MindCare เป็นเครื่องมือสนับสนุนสุขภาวะเบื้องต้น **ไม่ใช่การวินิจฉัยโรค** และไม่ทดแทนผู้เชี่ยวชาญ

## โมดูลหลัก

| Module | Path |
|--------|------|
| AI Companion (Agentic) | `/chat` |
| Mood Tracker | `/mood-tracker` |
| Emotion Analysis | `/emotion` |
| Mental Health Screening (PHQ-9) | `/phq9` |
| AI Recommendation | `/recommendations` |
| Wellness Articles | `/resources` |
| Stress Relief Activities | `/games` |
| AI Journal | `/journal` |
| AI Insight + Weekly Report | `/insight` |
| Goals & Habits | `/goals` |
| AI Motivation | `/motivation` |
| Emergency Support | `/emergency` |
| Teacher / Parent / Admin | `/teacher` `/parent` `/admin` |
| About / Research themes | `/about` |

## ติดตั้ง

```bash
npm install
cp .env.example .env.local
npm run dev
```
